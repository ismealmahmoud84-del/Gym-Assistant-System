IMPORTANT: .env file content is intentionally not handled by the delivery scripts.

This project loads environment variables from: .env (BASE_DIR / '.env').
Copy `.env.example` to `.env` before running.

What to set (typical):
- DJANGO_SECRET_KEY
- DJANGO_DEBUG (True/False)
- DJANGO_ALLOWED_HOSTS (comma-separated)
- CSRF_TRUSTED_ORIGINS
- Any AI provider keys required by fitness_api/ai_service.py

Default values exist for local run, but you MUST provide a real SECRET_KEY for production.
